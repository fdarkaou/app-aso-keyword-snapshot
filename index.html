App Store keyword snapshot

See every US App Store search an iOS app is observed in: its position, the move since the previous collection run, popularity, difficulty, opportunity and the strongest other app in that result. Paste one competitor ASO response or a JSON array of them (one per app). With two or more apps the page also compares them and lists the searches they share. Nothing leaves your browser.

Optional: paste a report you saved earlier (CLI --format json or --state file) to see which searches are new, gone or moved since then.

Where to get the JSON

The input is the competitor ASO response from PeekPanda, an iOS competitor catalogue that keeps dated App Store evidence for each app. Call it once per app:

curl --get https://api.peekpanda.com/v1/competitors/ios/1234567890/aso \
  -H "Authorization: Bearer $PEEKPANDA_TOKEN" \
  -H 'x-genviral-tenancy: personal'

Over MCP this is the get_app tool with action aso. You need a PeekPanda account and an API key; the competitor ASO reference lists every field, and keyword metrics explained describes popularity, difficulty and opportunity.

How to read it

  • Position is the app's place in the observed App Store Search API result for a US English search, not the native App Store rank and not search volume.
  • Move compares with the newest earlier collection run in the stored history. One run means no move yet.
  • Popularity is Apple's weekly score (1 to 100, tier 1 to 5) or, where Apple reports nothing, PeekPanda's estimate tier ("est. low"). Neither is a search count. A dash means unavailable, not zero.
  • Opportunity = popularity × (100 − difficulty) ÷ 100, only from Apple's numeric score. Difficulty and opportunity are directional.
  • An app with no observed searches is not proof that it ranks for nothing.
